Unmask- versão bilíngue

Este é um protótipo de aplicativo web instalável (PWA), pensado para iPhone.

COMO TESTAR
1. Hospede os arquivos em um serviço HTTPS.
2. Abra o endereço no Safari do iPhone.
3. Escolha Português (Brasil) ou English na tela inicial.
4. Para instalar, use Compartilhar > Adicionar à Tela de Início.

RECURSOS
- 136 cartas, em inglês e português brasileiro.
- Escolha de idioma na abertura e troca pelo botão no topo.
- Três níveis, embaralhar, deslizar, avançar/voltar, favoritos e histórico.
- Guarda idioma, favoritos e histórico no próprio aparelho.
- Cache offline após a primeira abertura com internet.

Observação: o idioma escolhido fica salvo. Para voltar à tela de idioma, use o botão EN/PT no topo para alternar entre as línguas.
